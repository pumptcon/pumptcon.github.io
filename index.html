Pump Touch Controller (PUMTPCON)

모바일 기기를 통한 신개념
펌프 게임 컨트롤러

펌프티콘(PUMPTCON)은
Pump Touch Controller의 약어로
안드로이드 스마트폰과 태블릿 PC를 통한
터치 기반 반응형 컨트롤러 앱입니다.
윈도우 PC 기반 펌프 잇 업 라이즈와 X새니티 게임 및
펌프 기반의 각종 게임들에서 사용 가능합니다.

펌프티콘의 주요 장점

모바일 터치 환경에 맞춰 세심하게 설계된 핵심 기능들을 확인하세요.

간단한 PC 연동

윈도용 PC 리시버 프로그램을 켜고 화면에 보이는
IP 주소를 앱에 입력하면 간편하게 연동됩니다.

다양한 게임 모드 & 버튼 배열

싱글 1P / 싱글 2P / 하프 / 더블 4가지
플레이 방식을 지원하며, 아케이드 배열부터
모바일 최적화 및 건반형 배열까지 가로 화면에
최적화 된 다양한 버튼 배열을 제공합니다.

동시 입력 & 터치 진동

멀티 터치 지원해 여러 버튼 동시에 누를 수 있고
터치 진동 및 화면 꺼짐방지 기능을 지원 하며
단색과 네온 두가지 버튼 색상을 지원합니다.

Interactive Showcase

모드별 버튼 레이아웃 미리보기

탭을 클릭하여 펌프티콘의 다양한 발판 모드 모양을 직접 확인해 보세요.

Q / E / S / Z / C 키 세트로 구성된 표준 싱글 1P 5키 발판 레이아웃

How It Works

3단계 간편 연결 가이드

복잡한 설정 없이 쉽고 빠르게 PC와 연동할 수 있습니다.

1

PC 리시버 프로그램 실행

윈도우 PC에서 펌프티콘 리시버를 실행하고 화면에 출력되는 IP 주소를 확인합니다.

2

IP 주소 입력

스마트폰/태블릿PC 펌프티콘 설정에서 IP 주소를 입력합니다.

3

게임 플레이 시작!

자동으로 연결 완료 배지가 초록색으로 변경되면 게임을 플레이합니다!
